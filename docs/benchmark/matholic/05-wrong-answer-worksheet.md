# 매쓰홀릭 — 오답유형 학습지 (메꾸기 루프의 핵심) (2026-08-30 실측)

URL: `/workbook/new/wrong-type?step=1`
진입: 학습지 → 새 학습지 만들기 → [목적별 > **오답**]

> ★★ 우리가 만들려는 "내신 기출로 진단 → 추적 → 약점 메꾸기" 루프의 **완성형 참조 화면**.
> 스텝퍼가 다르다: `① 출제 구성 — ② 문제 편집 — ③ 학습지 설정`
> (유형별은 "①문제 선택"인데, 오답은 **"①출제 구성"** — 문제를 고르는 게 아니라 *학생을 고르면 문제가 결정*된다)

## 화면 골격 (3열)

### 1열: 학생 (0)
- `학생 선택` 버튼 → 학생 추가
- 비어 있으면 "학생을 추가해주세요"
- ★ **학생이 출발점**. 문제가 아니라 사람이 먼저다.

### 2열: 범위
- `단원 선택 ⇅` (필터 아이콘)
- **기간**: `2026-08-23 ~ 2026-08-30` (기본 최근 1주)
- 학생 미선택 시: "학생을 먼저 선택해주세요."
- ★ **오답의 범위 = 어느 기간에 틀린 것인가 + 어느 단원인가**

### 3열: 출제문항 구성
| 옵션 | 형태 | 값 | 기본 |
|---|---|---|---|
| **오답문제 추가** | 토글 | on/off | **on** — 틀린 문제 원본을 그대로 넣을지 |
| **오답유사 추가** | 라디오 | 없음 / 1개 / 2개 / 3개 | **없음** — 틀린 문제당 유사문제 N개 추가 |
| └ 오답유사 통일 | 토글 (하위 옵션) | on/off | off — 여러 학생의 유사문제를 같은 것으로 통일 |
| **출제문제 난이도** | 체크박스 **9종** | 개념 / 기본 / 실력(하) / 실력(중) / 실력(상) / 심화(하) / 심화(중) / 심화(상) / 고난도 | **전부 체크** |
| 최대 문제수 | 체크박스 + 프리셋 + 슬라이더 | 10/20/30 프리셋, 슬라이더 0~150 | 30 |

- 하단: `2. 문제 편집 →` (학생 미선택 시 비활성)

## ★★ 핵심 발견

1. **난이도가 9단계다** (유형별 화면의 분포 카운터는 5단계 — 개념/기본/실력/심화/고난도).
   여기선 실력·심화가 각각 하/중/상으로 3분할 → **표시는 5단계, 필터는 9단계**.
   우리 난이도는 1~10 정수라 매핑 가능.

2. **"오답문제 추가" + "오답유사 추가"의 분리**가 설계의 핵심:
   - 틀린 문제 **그대로** 다시 (복습)
   - 틀린 문제의 **유사** N개 (같은 유형 다른 문제 = 진짜 이해했는지 확인)
   - 둘 다 켜면 원본 1 + 유사 N 세트로 나감
   → 우리 twin-generator(숫자·조건 변형)가 "오답유사"에 정확히 대응

3. **"오답유사 통일"** — 여러 학생을 동시에 뽑을 때, 학생마다 다른 유사문제가 아니라
   같은 문제로 맞춰 인쇄 부담을 줄이는 옵션. (매쓰홀릭 랜딩 문구 "학생마다 오답 문제가
   달라도 과제는 한꺼번에 출제" 가 이것)

4. **기간 기반**: "최근 1주에 틀린 것" 이 기본. 오답은 시간축을 갖는다.
   → 우리 `diagnostics.items` / `session_results` 에 채점 시각이 있으므로 구현 가능.

5. 학생 다중 선택 가능(학생(0) 카운터) → **반 전체 오답 과제를 한 번에** 출제.

## 우리 대비

| 매쓰홀릭 | 우리 현재 | 필요 |
|---|---|---|
| 학생 선택 → 오답 자동 수집 | `recommended-problems` API 있음(약점 노드 기반) | 화면 없음 → 신규 |
| 기간 범위 필터 | 없음 | items/session_results 시각으로 가능 |
| 오답 원본 + 유사 N개 분리 | twin-generator 존재, 미연결 | 연결 |
| 오답유사 통일(다학생) | 없음 | 신규 |
| 난이도 9단계 필터 | difficulty 1~10 보유 | 매핑만 |
| 최대 문제수 | 없음 | 추가 |

→ **데이터는 있는데 화면이 없다**는 우리 상황이 여기서도 반복. 진단 3,950건 + QR 1,658건이
   이 화면 하나면 즉시 쓸모가 생긴다.

## 학생 선택 모달 = "학생관리" (실측)

좌: 학생 찾기 / 우: 담은 목록

- **탭 4종: 반 / 그룹 / 학년 / 수업** — 같은 학생을 네 축으로 찾는다
  (6월 문서의 "학년/반/그룹 3차원" + 수업 = 4차원)
- 검색창: 학생이름 검색
- 반별 섹션 + 각 섹션에 **[전체선택]** 버튼 → 반 단위 일괄 담기
- **"미배정"** 섹션 별도 — 반이 없는 학생도 누락 없이 노출
- 학생 칩마다 ⊕ 버튼으로 우측에 담김
- 우: `추가된 학생목록 (N)` + `선택완료` (0명이면 비활성)

★ 반 단위 전체선택 + 오답유사 통일 = **"반 전체 오답 과제 한 번에 출제"** 가 성립하는 구조.
★ 우리는 학생 선택 UI 가 화면마다 제각각(반 관리/학생 관리/처방 각각 다름) → 공용 컴포넌트로 뽑을 지점.
