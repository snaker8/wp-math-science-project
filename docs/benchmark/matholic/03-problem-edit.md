# 매쓰홀릭 — ❷ 문제 편집 심층 해부 (2026-08-30 실측)

URL: `/workbook/new/unit-group?step=2`

## 골격 — 2분할

### 좌: 선택한 문제 (시험지 배열)
- 문제가 **번호순 카드**로 배열: `01 [개념]` `02 [개념]` `03 [개념]` … (2열 그리드)
- 각 카드: 번호 + **난이도 배지** + 삭제(🗑) 버튼
- 상단 도구: `유형별 개념` / ↩(되돌리기) / 🔄(새로고침·재추출) / ▤(보기전환) / `정렬 ▾`
- 최상단에 `이름:` 입력줄 — 학습지 제목

### 우: 문제 교체·추가 소스 (탭 6종)
| 탭 | 역할 |
|---|---|
| 개요 | (미탐색) 전체 구성 요약 추정 |
| **쌍둥이·유사** | 선택 문제와 같은 유형의 변형 문항 후보 |
| 단원별 | 같은 단원 다른 문항 |
| 고난도 | 난이도 상향 후보 |
| 서술형 | 서술형 후보 |
| 내 폴더 | 교사가 모아둔 문항 |
- 우상단 `해설 보기` 토글
- 각 후보 카드: **👍 아이콘**(추천/적합 표시) + 유형코드(1.1.1 다항식의 사칙연산) + 소분류(다항식의 전개) + 문제 본문 + **[+] 추가 버튼**
- 하단: `← 1. 문제 선택` / **출제될 문제 수 68** / `다음으로 →`

## ★ 핵심 통찰

1. **"고르기"와 "바꿔끼우기"가 한 화면**에 있다.
   좌측은 완성될 시험지, 우측은 무한 후보 풀. 마음에 안 드는 문제를 지우고 우측에서 [+]로 채운다.
2. **쌍둥이·유사가 최상위 탭**(기본 선택 상태) — 문제 교체의 첫 수단이 "같은 유형 다른 문제".
   → 우리 `twin-generator`(숫자·조건 변형)가 정확히 이 자리에 들어가야 한다.
3. 👍 표시 = 시스템이 미는 후보. 판단 근거는 미확인(사용 빈도·정답률·대표성 추정).
4. 좌측 난이도 배지가 카드마다 붙어 있어 **구성 편중이 눈으로 보인다**.
5. 🔄 버튼 = 같은 조건으로 문제 재추출(주사위 굴리기) 추정 — 우리 "자동 출제"와 유사.

## 우리와의 대조

| 매쓰홀릭 | 우리 |
|---|---|
| 좌 시험지 배열 + 우 후보풀 2분할 | `exam-create` 에 SelectionTray(선택 트레이) 있음 — **골격은 유사** |
| 쌍둥이·유사 탭이 기본 | `similar`(출판교재유사) 별도 화면으로 분리됨 → 흡수 대상 |
| 고난도·서술형 탭 | 우리는 분류 데이터로 필터 가능(난이도·type) |
| 내 폴더 | 우리 book_groups/폴더 구조 대응 |
| [+] 원클릭 추가 | 우리도 선택 트레이에 담기 가능 |
| 출제될 문제 수 실시간 | 우리 SelectionTray 에 카운트 있음 |

→ **우리도 조각은 다 있는데 화면이 갈라져 있다.** exam-create + similar + twin-generator 를
   이 2분할 구조로 합치면 같은 경험이 나온다.

## 추가 관찰 (완전 로드 후)

- 좌측 시험지 카드에 **학원 로고 + QR 코드**가 상단에 자동 배치 → 인쇄물이 곧 채점 매체
  (우리 QR 채점 세션과 동일 개념)
- 좌측 문제 카드는 **본문·선택지까지 실제 렌더** — 편집 화면이 곧 미리보기
- 우측 후보 카드 버튼이 **2종으로 분리**:
  | 버튼 | 동작 |
  |---|---|
  | **🔄 교체** | 좌측에서 선택 중인 문제를 이 문제로 **대체** (번호 유지) |
  | **+ 추가** | 시험지에 **새 문항으로 추가** (총 문항 수 증가) |
  - 그 외 🔍(확대 보기), 👍(추천), 난이도 배지(개념 등)
- ★ 교체/추가 분리가 중요: "이 문제 대신 비슷한 다른 것"과 "한 문제 더"는 다른 의도.
  우리 화면에는 교체 개념이 없다(담기만 있음).
