## 확인된 옵션 (모달 하단부)

| 옵션 | 형태 | 값·동작 |
|---|---|---|
| 기간 표시 | 자동 생성 문자열 + [적용] | `(08.30 ~ 11.27) 공통수학1 (2022 개정) (26.08.30 02:17)` — 학습지명 자동 제안 |
| **기간** | 날짜 2개 (시작 ~ 종료) | 기본 오늘 ~ +3개월. `마지막 설정 기간 … [적용]` = 직전 설정 재사용 버튼 |
| 서술형 출제 안내 | 토글 + 숫자 입력 | off / `N번부터 설정` (서술형 시작 번호 지정) |
| **분할생성** | 토글 + 라디오 3종 + 숫자 | `문제 수로` / `등분으로` / `균등 분할` + `N문제씩 분할 생성하기` |
| 하단 | 버튼 | `← 2. 문제 편집` / **`학습지 생성 ✓`** |

★ **분할생성**이 눈에 띈다: 68문항을 한 장이 아니라 **N문제씩 여러 학습지로 쪼개서 동시 생성**.
  회차 학습(1회차·2회차…) 운영과 직결. 우리에겐 없는 개념.

★ **기간(제출기간)** 이 출제 시점에 박힌다 → 학습지 목록의 "제출기간" 칼럼과 연결.
  즉 출제 = 배포(과제 부여)까지 한 번에. 우리는 출제와 배포가 분리돼 있다.
