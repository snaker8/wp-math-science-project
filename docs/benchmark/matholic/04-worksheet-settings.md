## 확인된 옵션 (모달 하단부)

| 옵션 | 형태 | 값·동작 |
|---|---|---|
| 기간 표시 | 자동 생성 문자열 + [적용] | `(08.30 ~ 11.27) 공통수학1 (2022 개정) (26.08.30 02:17)` — 학습지명 자동 제안 |
| **기간** | 날짜 2개 (시작 ~ 종료) | 기본 오늘 ~ +3개월. `마지막 설정 기간 … [적용]` = 직전 설정 재사용 버튼 |
| 서술형 출제 안내 | 토글 + 숫자 입력 | off / `N번부터 설정` (서술형 시작 번호 지정) |
| **분할생성** | 토글 + 라디오 3종 + 숫자 | `문제 수로` / `등분으로` / `균등 분할` + `N문제씩 분할 생성하기` |
| 하단 | 버튼 | `← 2. 문제 편집` / **`학습지 생성 ✓`** |

★ **분할생성**이 눈에 띈다: 68문항을 한 장이 아니라 **N문제씩 여러 학습지로 쪼개서 동시 생성**.
  회차 학습(1회차·2회차…) 운영과 직결. 우리에겐 없는 개념.

★ **기간(제출기간)** 이 출제 시점에 박힌다 → 학습지 목록의 "제출기간" 칼럼과 연결.
  즉 출제 = 배포(과제 부여)까지 한 번에. 우리는 출제와 배포가 분리돼 있다.

## 미확인 (뷰포트 상단 잘림 — 모달 내부 스크롤 불가로 캡처 실패)
- 학습지명 입력, 칼럼 수, 높이 균등화, 해설 포함 여부, 정답표 옵션 등
  (6월 요약 문서 §2-1 에 "칼럼 수(예 3칼럼)·높이 균등화·해설 보기" 기록 있음 — 이번에 재확인 못 함)
- 온라인 동시 출제(학생 앱 배포) 옵션 위치

## 우리와의 대조
| 매쓰홀릭 | 우리 |
|---|---|
| 출제 시점에 기간(제출기간) 지정 | 없음 — 출제 후 별도 배포 |
| 분할생성(N문제씩 쪼개기) | 없음 |
| 서술형 시작 번호 지정 | 없음 |
| 학습지명 자동 제안(범위+과정+시각) | 없음 (기본 `[날짜] 시험지`) |
| 칼럼·높이균등·해설 | 우리도 있음 (2단·배점·한글·헤더 5종) — ⚠ **매쓰홀릭 쪽을 못 봤으므로 우열 판단 불가** |

→ ❸단계에서 **확인된** 차이는 기간·분할생성·서술형 번호다. 그건 가져올 것이 맞다.

⚠ **정정 (2026-09-15)** — 전에 여기 "우리 인쇄 라인이 이미 더 강하다"고 적혀 있었다.
   그런데 바로 위 「미확인」 절에 칼럼 수·높이 균등화·해설 포함 여부는 **캡처 실패**라고 적혀 있다.
   **못 본 것 위에 쓴 판단**이었다. 게다가 이 문서는 설정 *모달*을 본 것이지
   **인쇄 결과물(조판)을 본 것이 아니다** — 조사서 01~10 어디에도 매쓰홀릭 인쇄물 캡처가 없다.
   대표 지적으로 드러났다. 조사서에 없는 것을 있는 것처럼 쓰지 않는다.
