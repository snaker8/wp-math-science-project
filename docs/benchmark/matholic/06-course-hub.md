## 3. 학생 탭 (기본 화면) — 반 운영의 핵심 대시보드

좌측 사이드: `학습목록` · `보고서` · `정오표` · `QR북` · **[교재비 청구]**(강조 버튼)
상단: `학생 관리` / `학생 삭제` 토글

| 칼럼 | 표시 | 예시 |
|---|---|---|
| 이름 | 드롭다운 + 제외 버튼 | 김태한 ⌄ ⊠ |
| **진행도** | % + 개수 + 진행바 | 90% 46개/51개 |
| **완료 학습수** | % + 개수 + 진행바 | 90% 46개/51개 |

| 보고서 목록 | 링크 | |

### ★★ 날씨 게이미피케이션
달성률을 **☀(맑음) / 🌤(구름조금) / ☁(흐림)** 아이콘으로 표시.
- 176% 달성 → ☀
- 71% 달성 → 🌤
- 0% 달성 → ☁
→ 숫자를 못 읽어도 **한눈에 이 학생이 잘하고 있는지** 보인다. 학부모 상담에서 강력.

### ★ 목표 대비 달성률 개념
"50개/70개", "88점/50점" — **주간 목표(학습량·정답률)를 설정**하고 그 대비 달성률(%)로 관리.
100% 초과도 그대로 표시(176%). 우리에겐 목표 설정 개념 자체가 없다.
