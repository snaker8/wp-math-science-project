## 0. 전체 골격

상단에 **3단계 스텝퍼**: `① 문제 선택 — ② 문제 편집 — ③ 학습지 설정` (우상단 X 로 닫기)
본문은 **4열 고정 레이아웃**:

| 열 | 제목 | 내용 |
|---|---|---|
| 1 | 과정 선택 | 학교급별 과정 체크박스 목록 (고등: 공통수학1/2·대수·미적분1/2·확률과통계·기하·기출과정·수학(상)/(하)·수학1/2·미적분·확률과통계 …) 각 항목에 `(22 개정)` 교육과정 표기 |
| 2 | 단원 및 유형군 선택 | 3단 트리 — 과정 > 대단원(1 다항식) > 중단원(1.1 다항식의 연산). 각 노드에 체크박스 + 펼침(+/−). 부분선택은 ■(반채움) 표시 |
| 3 | 유형 상세 편집 | 소단원 유형 목록 (1.1.1 다항식의 사칙연산, 1.1.2 다항식의 나눗셈 …). 각 행 체크박스 + `>` 상세 진입. 상단 토글: **[문제 이미지] [해설]** + **[자동 ▾]** |
| 4 | 출제문항 구성 | 옵션 패널 (아래 상세) |

★ 우리 `/dashboard/create` 는 3열(과목·단원 / 세부유형 / 미리보기)인데,
  매쓰홀릭은 **과정 → 단원트리 → 유형목록**을 각각 독립 열로 분리해 한 화면에서 좁혀 들어간다.

## 1. 출제문항 구성 패널 (4열) — 옵션 전수

### 기본 옵션
| 옵션 | 형태 | 값 | 기본값 |
|---|---|---|---|
| 대표문제 사용 | 토글 | on/off | **on** |
| 중복출제 방지 | 토글 | on/off | **on** |
| 답안 형태 | 라디오 | 전체 / 객관식 / 주관식 | **전체** |
| 유형별 문제수 | 라디오 | 1개 / 2개 / 3개 / 4개 | **2개** |

→ "유형별 문제수"가 핵심: **유형 N개 × 문제수 M = 총 문항**. 유형 2개 선택 + 2개씩 = 68문항 산출됨
   (실측: 1.1.1 + 1.1.2 체크 → 선택 68 / 출제 68)
→ "중복출제 방지" = 이미 출제한 문제 제외 (학생 이력 기반으로 추정)
→ "대표문제 사용" = 유형의 대표 문항 우선 배치

### 상세 설정 (접힘 → 펼침)
| 옵션 | 형태 | 값 |
|---|---|---|
| 최대 문제수 | 체크박스 + 프리셋 버튼 + 슬라이더 | 프리셋 10/20/25/30/50/150, 슬라이더 0~150 |
| 출제 방식 | 체크박스 + 라디오 | 단원·난이도별 맞춤 / 난이도별 맞춤 |

## 2. ★ 실시간 난이도 분포 카운터 (패널 하단, 항상 노출)

**5단계 난이도**: 개념 / 기본 / 실력 / 심화 / 고난도
2열 배치 — 좌: 개념·기본·실력 / 우: 심화·고난도
각 항목 = **라벨 + 가로 막대(비율) + 숫자**

실측값 (공통수학1 → 1.1.1 + 1.1.2 선택 시):
```
개념  ▬▬▬        14      심화   ▬▬▬▬▬   18
기본  ▬▬▬        14      고난도            0
실력  ▬▬▬▬▬      22
```
→ 유형을 체크하는 **즉시** 갱신. 선택을 늘리면 숫자·막대가 함께 늘어난다.
→ 하단 상태줄: `선택 68 | 출제 68` + 좌측 초기화(↺) 버튼 + 우측 `2. 문제 편집 →` (선택 0이면 비활성)

★★ 이것이 "탁탁 자유롭게"의 핵심 장치.
   유형을 고르는 순간 **난이도 구성이 눈에 보이고**, 편중되면 즉시 조정할 수 있다.
   우리 화면엔 이 피드백이 전혀 없다 (분류 데이터 5,897건으로 구현 가능).

## 3. 화면 동작 관찰

1. 과정 미선택 시 2·3열은 빈 상태 안내("과정을 선택해주세요") — 순차적 좁히기 강제
2. 과정 체크 → 2열 트리 + 3열 유형목록이 **동시에** 채워짐 (트리 클릭 없이도 전체 유형이 3열에 나옴)
3. 3열에서 유형 체크 → 2열 트리의 상위 노드가 ■(부분선택)로 변함 = 양방향 동기화
4. 난이도 분포·선택 카운트는 3열 체크와 즉시 연동
5. 유형 행의 `>` = 그 유형의 개별 문항을 열어 고르는 상세 편집 (미탐색 — 다음 조사)
