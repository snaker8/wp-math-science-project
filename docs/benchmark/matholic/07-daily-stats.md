# 매쓰홀릭 — 반 허브 > 일일학습 탭 (주간 캘린더) (2026-08-30 실측)

URL: `/course/{id}/daily-stats`

## 구조

- 상단: **[주간] 토글** · `< 2026년 8/24 ~ 8/30 >` (주 이동) · 날짜범위 직접입력 · `학습 이력` 버튼
- 헤더 행: `모두선택 (2)` + **요일 칼럼 7개** (8/24 월 … 30 일) — 각 요일에 체크박스, 토=파랑/일=빨강, 오늘 강조
- 행 = 학생. 이름 아래 **주간 달성 요약**(예: `61/70 (87%)`)
- 셀 = 그 날 그 학생이 한 학습들이 **색 칩**으로 쌓임

## 학습 칩 (실측 예시)

| 칩 | 색 | 해석 |
|---|---|---|
| `시중 14 / 17` | 분홍 | 시중교재 학습 14문항/17문항 |
| `확 27 / 32` | 주황 | (확률과통계) 27/32 |
| `학 10 / 10 ✓` | 주황 | 학습지 완료 |
| `동 1` `동 6` `동 2` `동 4` `동 9` | 초록 | 동영상 강의 N개 |
| `다 3 / 3 🔥` | 갈색 | (다시풀기?) 3/3 완료 표시 |
| `오 3 / 4` `오 3 / 3 🔥` | 남색 | 오답 학습 3/4 |

→ **학습 종류를 색+한 글자로 압축**해 한 셀에 여러 개를 쌓는다.
→ `N / M` = 푼 문항/전체, 🔥·✓ = 완료·연속 달성 표시(게이미피케이션).

## 핵심 통찰

1. **"이 학생이 이번 주 뭘 했나"가 한 화면**에 들어온다. 종류별로 구분되니 편중도 보인다.
   (김태한: 월~토 매일 활동 / 염예진: 수·토 동영상만 — 관리 필요가 즉시 드러남)
2. 요일 칼럼 체크박스 + 학생 체크박스 = **선택 후 일괄 작업**(과제 부여·클리닉 등) 도선 추정.
3. 주간 달성 요약(61/70 87%)이 학생 이름 밑에 — 학생 탭의 "금주 학습량"과 같은 지표.
4. 6월 문서의 "학습현황 주간 캘린더"는 **전 반 단위**(/learning-log), 이건 **반 내부** 버전.
   같은 개념이 두 레벨에 있다.

## 우리 대비

| 매쓰홀릭 | 우리 |
|---|---|
| 학생×요일 주간 캘린더 + 학습 종류 칩 | **없음** |
| 주간 달성률 요약 | 없음 (목표 개념 자체가 없음) |
| 요일·학생 선택 후 일괄 작업 | 없음 |

→ 우리 데이터로 만들려면: 채점 시각(session_results/items) + 학습 종류 구분(시험지/오답/진단)이
   필요. 시각은 있고, 종류 구분은 exam_type 으로 가능.
