## 2. 유형별 출제 화면 (`/workbook/new/unit-group?step=1`) — 사실

- 4열: 과정 선택(체크) → 단원 및 유형군 선택(트리) → 유형 상세 편집(소단원 체크 + `>` 로 유형군 펼침, [문제 이미지][해설][자동]) → 출제문항 구성.
- 출제문항 구성: **대표문제 사용**(토글, 기본 꺼짐, "각 문제 유형별 대표문제를 포함") · **중복출제 방지**(토글, 기본 켜짐,
  "최근 한달간 출제했던 문항을 제외") · **답안 형태** 전체/객관식/주관식 · **유형별 문제수** 1~4개(기본 4) ·
  상세 설정: **최대 문제수**(체크 + 슬라이더 0~150, 프리셋 10/20/25/30/50) · **출제 방식** 단원·난이도별 맞춤 / 난이도별 맞춤.
- 하단: 5밴드 분포(개념·기본·실력·심화·고난도) 막대+숫자, `선택 N | 출제 M`, [2. 문제 편집].
- 실측(중등 2-2, 1.1.1+1.1.2 체크): 개념 16·기본 34·실력 53·심화 47·고난도 0 → 선택 204 | 출제 150. 유형별 문제수 1개로 바꾸면
  분포만 바뀜(21/32/55/42, 합 150). 대표문제 사용 켜면 선택 255.

## 3. 데이터 흐름 (사실)

1. `GET payment /chapter/root/academy/` → 과정 루트, `GET payment /chapter/{id}/tree` → 단원 트리(chapterId).
2. `POST jellyg /api/opentextbook/repUnits` `chapterIds=…&containStatementUnit=true` → 소단원별 **유형군(unitGroup)** 과 대표문제.
3. `POST jellyg /api/opentextbook/units/v3` `{encryptIds:[unitGroupEncrypt…]}` → 유형군별 **문항 목록 전체**. 문항 필드:
   `tagLevel`(난이도 코드) · `level` · `answerType`(ONE/…) · `highPriority` · `representative` · `accuracy`(정답률 %) ·
   `aspectRatio` · `filePathMd5/answerFilePathMd5`(이미지) · `unitGroupStandardName`(유형 코드, 예 `m2211101`) · `subGroupName`(유형명) · `similarGroup`.
4. **분포 계산·문항 선정은 전부 브라우저(JS)에서** 한다. 서버는 후보만 준다. (번들 `SelectWorkbookCreateTypeScreen-*.js`)

## 4. 선정 알고리즘 (번들에서 읽음 — 코드가 아니라 규칙만 옮김)

- 난이도 코드: `-1 개념 · 11 기본 · 21/22/23 실력(하/중/상) · 31/32/33 심화(하/중/상) · 41/42/43 고난도(하/중/상)`. 5밴드로 묶어 표시.
- 후보 = 선택한 유형군마다 `sub.slice(0, 유형별 문제수(기본 4))` + (대표문제 사용이면 rep 1개). 답안 형태로 필터.
- `선택` = 후보 수, `출제` = min(후보, 최대 문제수(기본 150)).
- 출제 방식
  - **무작위/소단원별 균등**: 선택된 난이도 코드들을 밴드로 묶어 밴드마다 `round(n / 밴드수 / 밴드 안 코드수)` 를 할당, 코드별 풀은
    셔플(균등이면 소단원별로 묶어 라운드로빈), 할당만큼 뽑고 모자라면 남은 풀에서 채움.
  - **단원·난이도별 맞춤**: 단원×난이도 표에 직접 수를 넣음. **난이도별 맞춤**: 난이도별 수 → `wr`: 합이 n 을 넘으면 비례 축소 후
    **최대 나머지** 반올림(우리 `distributeByRatios` 와 같은 방식).
- 결과 정렬: 단원 순서 → 난이도 코드 순. 150 초과 시 "단원별로 고르게 무작위".
- 중복출제 방지 = 최근 1개월 출제 문항 제외 (학원 단위 이력).

## 5. 우리와 대조 → 적용할 것

| 매쓰홀릭 | 우리 현재 | 할 일 |
|---|---|---|
| 유형별 문제수 상한(1~4) + 대표문제 토글 | 유형별 최소 n(−/+) 만 | 상한·대표문제(우리는 "원본/대표" 없음 → 정답률 높은 기본문항) |
| 중복출제 방지(최근 1개월) 기본 켜짐 | 없음 | **1순위 구현** — 출제 이력 테이블 + 제외 기간 옵션 |
| 출제 방식 4종 | 단계 자동배분(난이도별 맞춤에 해당) | 무작위·소단원별 균등·단원×난이도 표 추가 |
| 최대 문제수 슬라이더 0~150 | 프리셋 10~30 + 입력 | 150 상한·슬라이더 |
| `선택 N | 출제 M` 실시간 | 가능 N/예상 N | 같은 의미 — 표기 통일 |
| 문항에 정답률(accuracy) | 없음 | 채점 이력 쌓이면 정답률 → 난이도 보정 |

## 6. 2단계 「문제 편집」 (`?step=2`) — 사실 (2026-10-13 직접 조작, 30문항)

- **좌 = 선택한 문제(시험지 미리보기 그대로)**. 상단: [유형별 개념](유형 개념 노트 삽입) · ↶ 되돌리기 · 🔄(빨강, 전체 재추출) · ≡ · 🔑(정답 보기) · **정렬 ▾**
  = 단원별 정렬 / 유형별 정렬 / 주관식 후순위 정렬 / 난이도 오름순 / 난이도 내림순 / 랜덤으로 섞기. 문항마다 번호·난이도 뱃지·🗑 삭제. 2단 A4, 학원 로고·QR·이름란이 1단계부터 보임.
- **우 = 탭 6개**: 개요 · 쌍둥이·유사 · 단원별 · 고난도 · 서술형 · 학원자료실 (+ [해설 보기]).
  - **개요**: 총 문제/단원 수, **난이도별 문제 분포**(「중심: 실력」 + `상세 난이도` 토글 → 실력(하)/(중)·심화(하)/(중)까지 쪼갬), 답안 유형 분포(객관식/주관식), 단원별 문제 분포.
  - **쌍둥이·유사**: 왼쪽에서 고른 문항의 **쌍둥이(twins)·유사 후보** 카드. 카드 = 👍(추천) · 난이도 뱃지 · 유형명(소그룹명) · 📂(자료실 담기) · 🔍 확대 · **[🔄 교체] [+ 추가]**.
    교체 = 그 자리 바꿈(문항 수 유지), 추가 = 끝에 붙음(30→31). 왼쪽에서 다른 문항을 클릭하면 후보가 그 문항 기준으로 바뀜.
  - **단원별**: 왼쪽 소단원 목록(1 도형의 성질 ▸ 1.1.1 …) → 오른쪽에 그 단원 문항을 **개념/기본/실력/심화 칩**으로 걸러 보여주고 [삭제]/추가. 유형 바깥(다른 소단원)에서 끌어오는 입구.
  - **고난도 / 서술형**: 선택 과정의 소단원 목록 → 고난도(tagLevel 41~43)·서술형(answerType STATEMENT)만 모아 보여줌. 없으면 "선택한 단원의 고난도 문제가 존재하지 않습니다".
  - **학원자료실**: 폴더(색 라벨) + 검색 + 목록/격자 + 정렬. "자주 쓰는 학습지·진단평가·문항을 모아 두는 공간" — 문항 단위 북마크를 출제 중에 바로 꺼냄.
- 하단: [← 1. 문제 선택] · `출제될 문제 수 N` · [다음으로 →].
- ⚠ 150문항으로 2단계에 들어가니 크롬 렌더러가 멈췄다(문항 이미지 150장 + 후보 로드). 30문항은 즉시. 우리도 미리보기 150장은 가상 스크롤/지연 로드가 필요하다.

## 7. 3단계 「학습지 설정」 (`?step=3`) — 사실

- 좌 = 학습지 미리보기(드래그 앤 드랍으로 순서 변경, 페이지 1/8 …). 우 = 설정 폼:
  - **학습지 제목**: 기본 제목 `중등 2-2 (2022 개정) (26.10.13 23:01)` / 과정·단원 표시 / 기간 표시 `(10.13 ~ 10.16) …` 각각 [적용] 버튼. **부제목**.
  - **기간** (시작~끝, 「마지막 설정 기간」 재적용). **서술형 출제 안내** 토글 + "N번부터 설정"(서술형을 뒤번호로 몰고 안내문).
  - **분할생성** 토글: 문제 수로 / 등분으로 / 균등 분할 → "N문제씩 분할 생성하기". **회차 출제**: 1회차/2회차/3회차(같은 구성을 회차별로). 출제 문항 수 N개.
  - **저장한 템플릿 적용** (+추가) — `GET jellyg /api/learningPrintTheme/template/academy`(학원 템플릿, 지금은 []).
  - **디자인 설정**: 최신(기본·초등·초등(없음)·초등(심플)·초등(파스텔)·초등(패턴)·중등·중등(패턴)) / 일반(패턴1 겹곡선 · 패턴2 빗금 · 패턴3 곡선 · 패턴4 사선 · 패턴5 둥근사각 · 스타일1 스마일 · 스타일2 반짝이 · 스타일3 원 · 시험지1 날짜형 · 시험지2 확인형 · 시험지3 모의고사형).
  - **정렬**: 단수 2단/3단 · 스마트 정렬(정렬 없음 / 1·2·3·4문제씩) · 문제 간 여백.
  - **문제지 설정**: ☑부제목 ☑문항 수 ☑QR ☐제목 첫페이지만 표시 · 모눈(없음…) · 난이도 표시(텍스트…) · ☑교재 출처 ☑시험지 출처.
- 하단: [← 2. 문제 편집] · [학습지 생성 ✓] (누르지 않음).

## 8. 2·3단계 API (실측, `rea/record3.api.jsonl` — 계정·결제·메시지·토큰 응답은 기록에서 제거)

## 9. 우리에 적용 — 우선순위 (대표 지시: "꼭 필요한 것은 적용, 우리 것 고수 X, 더 좋게 만들어도 됨")

6. ✅(#661) **개요** 블록(문제 편집 패널 위) — 난이도 5밴드 막대·객관식/주관식·소단원 수. 화면 안에서 계산.
