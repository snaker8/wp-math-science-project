# 중복 시험지 정리 — 중등 .hml 재임포트분 (2026-09-02)

## 무슨 일이 있었나

9/1 에 수학비서 .hml 자료를 다시 임포트하면서, **이미 자산화가 끝난 중등 기출이 한 벌 더** 들어왔다.
두 벌이 같은 시험지인데 제목이 달라서 중복으로 안 보였다.

| | 기존 | 재임포트 |
|---|---|---|
| 생성 | 2026-04~08 | 2026-09-01 |
| 경로 | OCR (Mathpix) | .hml 직접 파싱 |
| 제목 | `25-2-1-F 여명중 수학` | `25-2-1-F 여명중 중등수학2상` |
| 상태 | 유형분류 완료 · 검수됨 | 분류 미완료 |

제목이 갈린 이유는 `scripts/import-mathsecr.ts` 의 `buildTitle` 이 파일명 끝 교과서명을
그대로 붙이기 때문. 앞의 `25-2-1-F` 가 이미 학년·학기를 말하므로 중복 표기다.

## 판정 방법 (문항 수만으로는 부족)

본문 md5 로는 49쌍 중 6쌍만 일치했다. OCR 과 .hml 은 같은 문제라도 LaTeX 표기가 다르다.
그래서 **한글만 남긴 지문의 앞 20자**로 교집합을 셌다.

```sql
left(regexp_replace(content_latex, '[^가-힣]', '', 'g'), 20)
```

같은 학교·연도·학기·중간/기말 + 문항 수 동일 + 지문 90% 이상 일치 → 중복 확정.

## 처리 결과

- **중복 확정 37건** — 재임포트분(9/1) 소프트 삭제. 딸린 문제 **773문항**도 함께
  (전부 이 시험지에만 붙어 있었고, 542문항은 분류 대기열에 있었다 → 분류 비용 절감)
- **제목 정리 61건** — `중등수학2상` → `수학`
- **보류 12건** — 지문 일치 26~80%. 대부분 2025 중간고사(M). 대표 육안 확인 대상

## 되돌리기

삭제 표시를 **한 시각으로 못박아** 뒀다. 그대로 되돌린다.

```sql
update exams    set deleted_at = null where deleted_at = timestamptz '2026-09-02 13:00:00+00';
update problems set deleted_at = null where deleted_at = timestamptz '2026-09-02 13:00:00+00';
```

제목 되돌리기는 자동으로 안 된다(교과서명 정보가 제목에만 있었음). 필요하면 .hml 원본 파일명 참조.

## 재발 방지

- `buildTitle` 에 `normalizeSubjectLabel()` 추가 — 중등 교과서명은 `수학` 으로.
  고등(공통수학1·대수·미적분)은 실제로 갈리므로 유지.
- 남은 구멍: **같은 시험지를 다른 경로로 재임포트해도 막는 장치가 없다.**
  자산화 중복 가드(#1)는 `title + institute_id + book_group_id` 로 보는데, 제목이 다르면 통과한다.
  학교·연도·학기·중간기말로 보는 가드가 필요하다. (미착수)
