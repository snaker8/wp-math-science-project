## 0. 한 줄 결론

**출제 진입을 하나로 만들고(`/dashboard/exam/new`), 소스를 고른 뒤 3단계로 흐르게 한다.
그 끝은 이미 완성된 우리 인쇄 라인(ExamPaperView)에 그대로 인계한다.**

## 1. 목표 화면 구조

```
[출제] 메뉴 → "새 시험지 만들기" (진입 하나)
        ↓
❶ 소스 선택 — "무엇을 근거로 뽑을까"
        ↓
❷ 문제 선택 — 4열: 과목/과정 → 단원트리 → 유형목록 → 출제 구성(★난이도 분포 카운터)
        ↓
❸ 문제 편집 — 좌: 시험지 배열 / 우: 후보풀(유사·고난도·서술형·기출) [교체][추가]
        ↓
❹ 시험지 설정 — 제목·기간·분할 → 저장
        ↓
[기존 인쇄 라인] exam-management / ExamPaperView (2단·배점·한글·헤더) — 무변경
```

## 2. ❶ 소스 선택 — 우리 강점을 첫 칸에

매쓰홀릭은 13종(교재연계 3·내신수능 6·초등 1·문제은행 2·목적별 4).
우리는 **가진 것 + 강점 순서**로 6종에서 시작한다.

| 순 | 소스 | 근거 데이터 | 상태 |
|---|---|---|---|
| **1** | **우리 학원 기출** ★강점 | 학교기출 141건, 출처 100%(학교·연도·중간/기말) | 즉시 가능 |
| 2 | 유형별 | 수학비서 2,573 유형 + 분류 5,897건 | 즉시 가능 |
| 3 | 단원별 | 같은 분류 데이터 | 즉시 가능 |
| 4 | **오답(학생별)** ★루프 | 진단 items 2,746 + QR 1,658 + 숙달 3,950 | 즉시 가능 |
| 5 | 고난도·서술형 | difficulty + problems.type | 즉시 가능 |
| 6 | 시중교재 유사 | 시중교재 자산화 1건 → **축적 대상** | 데이터 쌓이는 만큼 |

★ 매쓰홀릭에 없고 우리에게 있는 것: **"그 학교 기출로 그 학생을 추적"**.
   매쓰홀릭은 전국 10만 DB(넓이), 우리는 우리 학원 학교 기출(정밀).
   → 소스 1번을 **학교·학년·학기·중간/기말 4단 좁히기**로 만든다. 우리만의 첫 화면.

## 3. ❷ 문제 선택 — 4열 + 난이도 분포 카운터

참조: `benchmark/matholic/02-problem-select.md`

| 열 | 내용 | 우리 데이터 |
|---|---|---|
| 1 | 과목·과정 (중1-1 … 미적분) | curriculum_codes / mathsecr 과목 |
| 2 | 단원 트리 (대→중단원, 부분선택 ■) | mathsecr_types 계층 |
| 3 | 유형 목록 (소단원 유형 + `>` 개별문항) | mathsecr leaf + problems |
| 4 | **출제 구성 패널** | 아래 |

### 출제 구성 패널 (4열)
| 옵션 | 값 | 우리 구현 |
|---|---|---|
| **★난이도 분포 카운터** | 개념/기본/실력/심화/고난도 5단 + 막대 + 실시간 | classifications.difficulty(1~10) → 5밴드 매핑. **최우선** |
| 유형별 문제수 | 1/2/3/4개 | 유형 × N 배분 |
| 답안 형태 | 전체/객관식/주관식 | problems.type |
| 최대 문제수 | 프리셋+슬라이더 | 상한 컷 |
| 중복 출제 방지 | on/off | 학생 이력(session_results) 대조 — 2차 |
| 대표문제 우선 | on/off | usage_count 기준 — 2차 |

★★ **난이도 분포 카운터가 이 화면의 심장**이다. 유형을 고르는 즉시 구성이 보이고
   편중되면 바로 조정 — 이것이 "탁탁 자유롭게"의 실체 (실측: 개념14/기본14/실력22/심화18/고난도0).

## 4. ❸ 문제 편집 — 2분할 + 교체/추가

참조: `benchmark/matholic/03-problem-edit.md`

- **좌**: 선택 문제 번호순 배열(난이도 배지·삭제·정렬). 우리 `SelectionTray` 확장
- **우**: 후보풀 탭 — `유사(기본)` / `기출` / `고난도` / `서술형` / `내 폴더`
- 각 후보에 **[교체]**(번호 유지·대체) / **[추가]**(새 문항) **두 버튼 분리** ← 우리에 없는 개념
- 유사 후보 = **①같은 유형 다른 문제(DB) + ②twin-generator 변형(숫자·조건)**
  → AI 변형은 비용 발생 → 해설 PIN 게이트와 같은 방식으로 통제 검토

## 5. ❹ 시험지 설정 → 인쇄 라인 인계

- 제목(자동 제안: 범위+과정+시각), **기간(제출기간)**, 서술형 시작번호, **분할생성(N문제씩)**
- 저장 → exams 레코드 생성 → **기존 exam-management/ExamPaperView 로 이동**
- ★ 인쇄·조판·한글 출력은 **손대지 않는다** (이미 우리가 더 강함)

## 7. 구현 순서

| 단계 | 내용 | 산출 |
|---|---|---|
| **S1** | ❷ 문제 선택 + **난이도 분포 카운터** | 체감 최대. 데이터 이미 보유, AI 비용 0 |
| **S2** | ❶ 소스 선택 (우리 학원 기출 첫 칸) + ❹ 저장→인쇄 인계 | 한 흐름 완주 |
| **S3** | ❸ 문제 편집 2분할 + 교체/추가 + 유사 후보(DB) | 편집 자유도 |
| **S4** | 오답 소스 (학생 선택 → 기간 → 오답원본/유사 N) | ★메꾸기 루프 진입 |
| **S5** | twin-generator 연결 (AI 변형 후보) ★비용 | PIN 게이트 검토 |
| **S6** | 유형 숙달 매트릭스 (진단 3,950건 시각화) → 약점→출제 원클릭 | 루프 완성 |
