## 1. 확정된 사실 (실측)

### 분류 파이프라인 실제 흐름 (`src/lib/workflow/classify.ts`)
```
1차 (전면): Claude Sonnet 4.6   ← CLAUDE_CLASSIFY_MODEL, "한국어 분류 정확도 최고"
   ↓ 실패·빈 응답
2차 (폴백): Gemini Flash        ← CLASSIFY_GEMINI_MODEL
   ↓ 빈 응답
3차 (폴백): GPT-4o / GPT-4.1-mini
```

### cloud-flow.ts
- `OPENAI_MODEL = 'gpt-4o'` → **과학·해설·빠른정답 분기용 폴백** (주석 명시)
- `ANTHROPIC_MODEL = 'claude-sonnet-4-6'` → 풀이 생성 전담

### ★ 조사 시 주의 (실패 사례)
- **문자열 grep 으로 모델 수를 세면 안 된다.** "gpt-4o 18곳"으로 나왔지만 대부분 **폴백 자리**였다.
  전면은 Sonnet 4.6. 반드시 **조건문·환경변수·실패 분기까지 따라가서** 실제 호출 흐름을 봐야 함.
- 파일 상단 주석이 옛 구조로 남아 있음 (`classify.ts` L2: "Gemini Flash + GPT-4o 폴백")
  → 현재 구조와 불일치. 코드 읽는 사람 오해 유발. 정리 대상(사소).

## 2. 아직 확인 못 한 것 (다음 세션에서)

### (a) 이미지만으로 전 과정이 되는가
- 사용자: "분명 예전에 시도했던 것들" → **왜 멈췄는지부터** 찾아야 함 (같은 실패 반복 금지)
- 찾을 곳: 커밋 이력, 코드 주석, `src/lib/vision/image-interpreter.ts`, `reanalyze-crop`

### (b) 과학 PDF 업로드 시 걸린 것
- 사용자 증언: **텍스트는 상관없는데 수학 수식 렌더·그래프·도형**이 문제였음
- 지금도 남아 있는지 확인 필요

### (c) Mathpix OCR API 최신화 여부
- 만든 지 오래됨. 현재 버전·옵션(수식·표 처리 개선분) 반영 상태 미확인

### (d) 모델 최신화 여지
- Sonnet 4.6 이 전면이므로 급하지 않음. 폴백단(gpt-4o)은 정리 여지
- ★ 교체 시 **분류 정확도 회귀 위험** — 반드시 비교 검증 후
