## 0. 왜 필요한가 — 진행도가 없다

매쓰홀릭 반 허브 학생 탭의 첫 칼럼 **「진행도 90% 46개/51개」** 는 *완료한 학습 회차 / 수업의 전체 회차* 다.
우리 학생 탭의 진행도는 **제출한 과제 / 배정된 과제** 로 대신하고 있다(단계 8). 과제가 낱개라 「이 반이 어디까지 왔나」가 없다.

매쓰홀릭 실측(확률과 통계 -개념진도반):
```
수업(course) = 과정 하나의 맞춤편집 교재 한 권  (162쪽 · 442문항 · 51회차 · 범위 1.1 ~ 3.3)
  └ 학습(회차) 51개 = 소단원 × 회차   1.1.1 중복순열 1회차 (1) · 2회차 (2) · 3회차 (3) · 1.1.2 … (4) …
       회차마다 난이도 계단: 1회차 개념 9 · 기본 1  →  2회차 기본 6 · 실력(하) 4  →  3회차 실력(하) 6 · 실력(중) 1
       각 회차 = 학생마다 제출/점수 + 오답유사 학습이 짝
```
회차가 있어야 생기는 것: **진행도** · 학습 탭(회차 카드 · 평균점수 · 전원/일부/미제출) · 출력(회차별 학습/오답유사) · 설정의 회차별 문제수 그래프 · 일일학습.

## 2. 제안 — 테이블 2개, 컬럼 1개

```
courses            id · institute_id · class_id · subject_code(MS05) · title
                   settings jsonb { issueMode: 'common'|'personal', perStep: 10, ladder: [...] }
                   created_by · created_at · deleted_at
course_steps       id · course_id · seq(1..N) · unit_code(소단원 depth4) · label("1회차")
                   level_plan jsonb { A: 9, B: 1 }      ← 이 회차의 난이도별 문항 수 (계단)
                   assignment_id (null = 아직 안 냄) · issued_at
assignments        + course_step_id (nullable)          ← 과제가 어느 회차인지. 낱개 과제는 null 그대로
```
- **코스 = 반 하나에 과정 하나.** 매쓰홀릭 「수업」과 1:1. 반은 여러 코스를 가질 수 있다(중3-1 · 중3-2).
- **회차 = 소단원 × 난이도 계단 한 단.** 문항은 회차를 「낼 때」 뽑는다 — 미리 박아 두면 문제은행이 자라도 못 쓴다.
- **진행도 = 학생이 제출한 회차 수 / 코스 회차 수.** 제출은 `assignment_id → exam_id → 채점 세션` 으로 매번 계산 (단계 3 원칙 그대로).
- **잃는 것: 없다.** 기존 과제·시험지·채점은 그대로. `course_step_id` 는 nullable 로 붙인다.

### 회차 계단 자동 생성 규칙 (매쓰홀릭 실측을 그대로)
소단원마다 문제은행 공급(층별 문제 수)을 보고:
```
개념층 있음        → 1회차: 개념 위주 (개념 n₁ + 기본 1)
기본층 있음        → 2회차: 기본 위주 (기본 n₂ + 실력하 …)
실력층 있음        → 3회차: 실력 (실력하 + 실력중)
심화층 있음(≥3)    → 4회차: 심화
```
회차당 문항 수 `perStep`(기본 10, 매쓰홀릭 회차 문항 실측 7~14). **공급이 모자란 층은 회차를 만들지 않고 표시만** —
문제은행 완성도 40%인 지금은 소단원 절반이 1~2회차로 끝난다. 그게 사실이고, 분류가 붙으면 회차가 늘어난다.
계단은 `settings.ladder` 로 코스마다 바꿀 수 있게.

### 출제 방식 (매쓰홀릭 설정 탭 「개인화 학습 / 공통 출제」)
- **공통**: 회차 하나 = 시험지 한 장, 전원 같은 문제 (지금 from-problems 그대로)
- **개인화**: 회차 하나 = 학생마다 다른 문제 — 시험지 N장. 2차. (cell-problems 에 `excludeSeen` 이 이미 있어 학생별 추출은 된다)

## 3. 화면 — 반 허브에 어떻게 얹나 (탭을 늘리지 않는다)

| 탭 | 지금 | 코스 층 뒤 |

## 5. 판단이 필요한 것 (대표)

| 항목 | 선택지 | 제안 |
|---|---|---|
| 회차의 단위 | 소단원(depth4) / 중단원(depth3) | **소단원** — 매쓰홀릭 실측(1.1.1 중복순열 1~3회차). 227개 소단원 × 1~4회차 = 중3-1 코스 300~600회차. 많다면 「학습한 단원만」처럼 범위를 골라 만든다 |
| 회차당 문항 | 고정 10 / 소단원 공급 따라 | **기본 10, 코스 설정으로** |
| 코스 시작 조건 | 문제은행 완성도 무관 / 40% 이상 | **무관** — 모자란 층은 안 만들고 표시. 분류가 붙으면 「회차 다시 계획」 |
| 착수 시점 | 지금 / PR #522 머지·사용 후 | **머지·사용 후.** 반 허브를 한 번 실제로 굴려 본 뒤가 안전하다 |
