# 학생 대시보드 리디자인 브리프 (Claude Design용)

## 제품 컨텍스트
- **과사람 수학 프로그램** — 한국 학원·학교용 수학 문제은행 + LMS
- 학생은 중·고등학생 (13~18세)
- 스마트폰 + 태블릿 + PC 모두 사용 (모바일 우선)
- 수학 문제 풀이·채점·복습이 주 목적

## 현재 상태 (수정 대상)
- 이미 밝은 톤 적용 (bg-gray-50, indigo accent)
- 하지만 브랜딩 불일치: "With-People" → "과사람" 으로 통일 필요
- 반응형: `max-w-md mx-auto md:max-w-4xl md:p-6` — 데스크톱에서 너무 좁음
- 모바일 하단 탭: 홈/학습/AI튜터/내정보 (4개)
- 페이지 711줄로 기능 나열식 — 정보 우선순위 불분명

## 리디자인 목표

### 정보 위계 (위에서 아래)
1. **오늘 해야 할 것** (추천 문제, D-Day 시험) — 가장 크게
2. **학습 진도** (원형 차트 또는 히트맵)
3. **최근 성적 추이** (꺾은선 그래프, 7일)
4. **취약 단원 Top 3** (약점 강조)
5. **강사 공지/메시지**
6. **초대받은 반** (있을 때만)

### 레이아웃
- **모바일 (≤640px)**: 세로 스크롤, 카드 1열
- **태블릿 (640~1024px)**: 2열 그리드
- **데스크톱 (≥1024px)**: 왼쪽 메인(2/3) + 오른쪽 사이드(1/3, 공지·알림)
- 상단 헤더: 학생명 + 아바타 + 환영 메시지
- 모바일 하단 고정 탭(현재 방식 유지)

### 비주얼
- **primary**: Indigo (현재 유지, `indigo-600`)
- **secondary accent**: 따뜻한 주황/노랑 (학습 성과 강조용)
- **경고**: 빨강 (취약 단원, 미완료 과제)
- **배경**: `bg-gray-50` 기본, 카드는 `bg-white` + 부드러운 그림자
- **라운드**: `rounded-2xl` 이상 (학생 친화적, 말랑한 느낌)
- **타이포**: Pretendard, 크기 큼 (학생이 보기 편하게)
- **아이콘**: Lucide (현재 유지), 크게 (`h-6 w-6` 이상)

### 인터랙션
- 카드 hover: 미세 scale + shadow 진하게
- CTA 버튼은 눈에 띄게 (풀칼라 indigo + 화살표)
- 진도/점수 숫자 카운트업 애니메이션
- 프로그레스 바는 그라디언트 (학생 동기부여)

### 감성 톤
- **친근하면서 진지** — 너무 유치하지도, 차갑지도 않게
- 일러스트 최소 (혹은 기하학적 심플 도형)
- Duolingo 정도의 따뜻함 + Notion 정도의 깔끔함

### 피할 것
- 어두운 테마 (학생 UX엔 맞지 않음)
- 복잡한 차트 (학생이 이해 못 하는 지표)
- 과도한 그라디언트·네온 (교육 플랫폼 신뢰감 훼손)
- 여러 색 동시 사용 (indigo 중심, 최대 3색)

## 반드시 유지할 컴포넌트
- 하단 모바일 탭 네비 (홈/학습/AI튜터/내정보)
- 수식 렌더는 KaTeX 그대로
- Supabase 데이터 구조 (enrolledClasses, pendingInvitations, completedExams)
- Lucide 아이콘

## 출력 형식
Claude Code 핸드오프 번들로 익스포트 (tsx 컴포넌트 + Tailwind 클래스)
