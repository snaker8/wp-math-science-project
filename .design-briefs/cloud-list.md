# 시험지 목록 페이지 리디자인 브리프 (Claude Design용)

## 제품 컨텍스트
- **과사람 수학 프로그램** — 한국 학원·학교용 수학 문제은행 + LMS
- 사용자: **학원장 / 강사** (시험지 진입 허브)
- 업무: 저장된 시험지 목록 탐색 → 선택 → 편집/인쇄로 이동
- 현재 페이지: `src/app/dashboard/cloud/page.tsx`
- em-management, cloud-exam-editor와 **동일한 Chrome 디자인 시스템**

## 현재 구조
- 업로드 버튼 상단
- 그룹(폴더) 트리 + 시험지 리스트 (flat)
- 최근 업로드된 시험지 표시

## 리디자인 목표

### 레이아웃
```
[ topnav (56px) ]
[ sidebar (280px)   · main (1fr)                  ]
[ 시험지 그룹 트리  · 헤더 + 필터 + 시험지 grid    ]
```

### 좌측 사이드바 (280px)
- Chrome 다크 팔레트
- **그룹 트리**:
  - 학년/학기/과목별 폴더
  - 각 폴더에 시험지 수 배지
  - 드래그&드롭 순서 변경
- 하단: "새 그룹 만들기" 버튼 (indigo)

### 메인 영역
- **상단 Subbar**:
  - 브레드크럼 (← 대시보드 / 과사람 클라우드)
  - 선택된 그룹 제목 (편집 가능)
  - 우측: 검색창 + 정렬 (최신순/이름순/문항수) + 보기 모드 (카드/리스트) + 업로드 CTA
- **필터 바** (sticky):
  - 상태 필터 (전체/작업중/완료/배포됨)
  - 과목 필터 (수학/과학 pills)
  - 학년 필터
- **시험지 그리드** (3~4열 카드):
  - 각 카드:
    - 상단: 시험지 제목 + 배치 드롭다운
    - 중앙: 미니 난이도 분포 바 (5단계 색상 segment)
    - 하단 메타: 문항수 · 과목 · 최근 수정일
    - 호버: 그림자 강화 + 미리보기 빨리 열기 버튼

### 인터랙션
- 카드 클릭 → `/dashboard/cloud/[examId]` 이동
- 카드 우클릭 → 컨텍스트 메뉴 (복제/삭제/이동/공유)
- 검색어 입력 → 실시간 필터
- 빈 상태: 큰 업로드 zone + "첫 시험지 업로드하기" CTA

## 반드시 유지
