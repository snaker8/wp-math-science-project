# 문제은행 페이지 리디자인 브리프 (Claude Design용)

## 제품 컨텍스트
- **과사람 수학 프로그램** — 한국 학원·학교용 수학 문제은행
- 사용자: **학원장 / 강사** (수학비서 22,785 유형 기반 문제 검색)
- 업무: 단원/유형/난이도로 필터 → 문제 선택 → 시험지 편성
- 현재 페이지: `src/app/dashboard/repository/page.tsx`
- em-management 등과 **동일한 Chrome 디자인 시스템**

## 기능 요구 (수학비서 참조)
- **단원/유형 트리 필터** (18과목 × 소단원 × 3,000세부유형)
- 난이도 체크박스 (1~10)
- 문제 검색 (텍스트/수식)
- 선택한 문제를 "카트"에 담기 → 새 시험지 생성

### 좌측 사이드바 (320px)
- Chrome 다크
- **과목 선택 세그먼트** (수학 / 과학)
- **단원 트리** (아코디언 확장):
  ```
  ▸ 공통수학1
    ▸ 다항식
      · 다항식의 연산 (123개)
      · 나머지정리 (87개)
    ▸ 방정식과 부등식
  ```
- **난이도 필터** (1~10 체크 + 빠른 선택: 상/중/하 프리셋)
- **인지영역 필터** (계산/이해/추론/문제해결)

### 메인
- **상단**: 검색창 (큰) + 정렬 + 뷰 모드 (리스트/카드/트리)
- **필터 바** (활성 필터 칩들 · X로 제거 가능 · 전체 삭제)
- **문제 그리드/리스트**:
  - 각 문제: 번호 + 미니 프리뷰 + 난이도/영역 배지 + 체크박스
  - 호버: "미리보기" / "카트 담기" / "유사문제 생성" 액션 버튼

### 우측 카트 패널 (320px)
- **상단**: 선택된 문제 수 + 삭제 버튼
- **선택 문제 리스트** (드래그로 순서 변경)
- **하단 CTA (큰)**:
  - "새 시험지로 만들기" (primary indigo)
  - "기존 시험지에 추가" (secondary)
