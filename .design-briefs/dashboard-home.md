# 대시보드 홈 리디자인 브리프 (Claude Design용)

## 제품 컨텍스트
- **과사람 수학 프로그램** — 한국 학원·학교용 수학 문제은행 + LMS
- 사용자: **학원장 / 강사** (앱 진입 첫 페이지)
- 업무: 최근 작업 / 알림 / 빠른 액션 / 통계 확인
- 현재 페이지: `src/app/dashboard/page.tsx`
- em-management와 **동일한 Chrome 디자인 시스템**

## 정보 위계 (위 → 아래)
1. **환영 헤더** — 학원명 + 오늘 날짜 + 간단한 주간 요약
2. **Stat 타일 4개** — 총 시험지 / 문제은행 문제 수 / 이번주 처리 / 알림
3. **빠른 액션 3개** (큰 카드):
   - PDF 업로드 → OCR
   - 문제은행에서 시험지 만들기
   - 배포된 시험지 채점 보기
4. **최근 시험지** — grid 4열 카드 (미니 시험지 프리뷰)
5. **최근 알림 / 배포 현황** — 리스트

## 레이아웃
```

```

### 환영 헤더
- 배경: `chrome-surface` 카드 + 미묘한 그라데이션 오버레이
- "안녕하세요, {학원장} 원장님 👋"
- 주간 요약: "이번주 12개 시험지 생성, 234개 문항 추가됨"

### Stat 타일 (4열 grid)
- 각 타일: 아이콘 + 숫자 (카운트업 애니) + 라벨 + 증감률
- 배경: `chrome-card`, 호버: `chrome-raised`
- 액센트 색은 indigo만 (통일)

### 빠른 액션 (3열 grid of 큰 카드)
- 각 카드: 아이콘 + 제목 + 설명 + "시작하기" 화살표
- 호버: 그림자 강화 + scale 1.02
- 색상: 카드별 subtle indigo/cyan/teal (신중히 선택)

### 최근 시험지
- 4열 grid
- 각 카드: 시험지 제목 + 문항수 + 난이도 분포 미니 바 + 최근 수정일
- 클릭 → 편집 페이지로 이동

### 알림 리스트
- 각 항목: 아이콘 + 메시지 + 시간 + 액션
- 읽지 않음: indigo dot 좌측

## 색상
- Chrome 팔레트
- indigo primary, cyan secondary
- 복잡한 그라데이션 피할 것

## 출력
Claude Code 핸드오프 번들.
